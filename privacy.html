Privacy

Short version: the app collects nothing about you. No ads, no analytics, no account, no tracking.

The app

  • Your progress and settings are stored only on your phone. They never leave it unless you copy your save yourself (Settings → copy save).
  • Once a day, on the home screen, the app asks GitHub (api.github.com) whether a newer version exists. Like any web request this sends your IP address and the app's technical user agent to GitHub. Nothing else is sent. See the GitHub privacy statement.
  • Permissions: internet (only for that version check) and vibration (for haptic feedback, can be turned off).

This website

This page is hosted on GitHub Pages. GitHub may log your IP address when you visit it, for security reasons. The page itself sets no cookies, loads no external fonts or scripts and has no analytics. The trailer is hosted on Vimeo and is only loaded when you click it; then Vimeo receives your IP address and browser details (we request its do-not-track mode). See the Vimeo privacy policy.

Contact

Questions: open an issue at github.com/SlayerTO/miso-sudoku.

Datenschutz

Kurz: Die App erhebt keine Daten über dich. Keine Werbung, keine Analyse, kein Konto, kein Tracking.

Die App

  • Dein Fortschritt und deine Einstellungen liegen nur auf deinem Handy. Sie verlassen es nie, außer du kopierst deinen Spielstand selbst (Einstellungen → Spielstand kopieren).
  • Einmal am Tag fragt die App auf dem Startbildschirm bei GitHub (api.github.com) nach, ob es eine neue Version gibt. Wie bei jedem Webaufruf werden dabei deine IP-Adresse und die technische Kennung der App an GitHub übertragen. Sonst nichts. Siehe die Datenschutzerklärung von GitHub.
  • Berechtigungen: Internet (nur für diese Versionsprüfung) und Vibration (für haptisches Feedback, abschaltbar).

Diese Webseite

Diese Seite liegt auf GitHub Pages. GitHub kann beim Aufruf deine IP-Adresse aus Sicherheitsgründen protokollieren. Die Seite selbst setzt keine Cookies, lädt keine externen Schriften oder Skripte und nutzt keine Analyse. Der Trailer liegt bei Vimeo und wird erst geladen, wenn du ihn anklickst; dann erhält Vimeo deine IP-Adresse und Browserdaten (wir fordern den Do-not-track-Modus an). Siehe die Datenschutzerklärung von Vimeo.
